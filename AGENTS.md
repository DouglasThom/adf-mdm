# Repository guidance

This repository is documentation-only. Its purpose is to create a detailed instruction guide for using Azure Data Factory (ADF) with IBM Cloud Pak for Data Master Data Management (MDM) to retrieve data.

## Working rules

- Do not create source code, app scaffolding, deployment scripts, build tooling, or executable infrastructure artifacts.
- Treat ADF, MDM, Snowflake, and Azure steps as documented procedures unless the user explicitly asks for an executable artifact.
- Keep changes surgical and limited to documentation files.
- Ask before filling in unknown MDM API details, field names, credentials, tenant-specific URLs, or environment assumptions.
- Prefer clear checklists, decision records, validation steps, troubleshooting notes, and source links over implementation artifacts.
